# Вишлист на GitHub Pages

Сайт со списком желаний. Ссылка одна и та же всегда: добавили или удалили подарок — по ссылке сразу виден новый список.

## Как это работает

- Список хранится в файле `items.json` в вашем публичном репозитории.
- Страница при каждом открытии читает этот файл напрямую из GitHub и сама перепроверяет его каждые 2 минуты, пока вкладка открыта. Пересобирать или заново отправлять ссылку не нужно.
- Редактировать можно двумя способами: прямо на сайте (кнопка «Редактировать») или вручную, поправив `items.json` на github.com.

## Запуск за 5 минут

1. Создайте на GitHub **публичный** репозиторий, например `wishlist`.
2. Загрузите в него все файлы из этой папки (кнопка **Add file → Upload files**), включая `.nojekyll`.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/wishlist/`. Эту ссылку и отправляйте друзьям.

Если ветка называется не `main`, поменяйте `branch` в начале файла `app.js`.

## Редактирование прямо на сайте

Нужен личный токен GitHub (создаётся один раз):

1. GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. *Repository access* → **Only select repositories** → выберите ваш репозиторий.
3. *Permissions → Repository permissions* → **Contents: Read and write**.
4. Скопируйте токен (`github_pat_…`).
5. На сайте нажмите **«Редактировать»** и вставьте токен.

Токен сохраняется только в браузере на этом устройстве. Никому его не показывайте и не вставляйте в файлы репозитория. Каждое изменение сохраняется как обычный коммит, так что историю можно посмотреть и откатить на GitHub.

## Редактирование вручную

Откройте `items.json` на github.com → значок карандаша → внесите правку → **Commit changes**. Поля подарка:

Общие поля файла: `title`, `owner`, `description`, а также `eventName` и `eventDate` (дата в формате `2026-12-12`). Если указать дату, в шапке появится обратный отсчёт; пустая дата скрывает его. Эти поля можно менять и на сайте: «Редактировать» → «О списке».

Поля подарка:

| Поле | Что это |
|---|---|
| `id` | любая уникальная строка |
| `title` | название (обязательно) |
| `url` | ссылка на товар |
| `image` | ссылка на картинку |
| `price`, `currency` | цена и валюта |
| `category` | категория для фильтра |
| `priority` | 1 — очень хочу, 2 — хочу, 3 — было бы здорово |
| `note` | заметка (размер, цвет) |
| `reserved` | `true` — уже подарено |

## Важно знать

- Список публичный: его видит любой, у кого есть ссылка (и поисковики, если ссылка нигде опубликована).
- Читатели без токена не могут ничего менять и отмечать подарки забронированными. Статус «Уже подарено» ставите вы.
- Без токена GitHub разрешает около 60 запросов в час с одного адреса. Если лимит исчерпан, страница автоматически берёт файл с самого сайта: тогда обновление может задержаться на 1–2 минуты.
- Если картинка товара не загружается, показывается значок подарка. Лучше брать прямую ссылку на изображение (оканчивается на `.jpg`, `.png`, `.webp`).
- Для своего домена впишите `repo: 'логин/репозиторий'` в начале `app.js`.
